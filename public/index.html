การเชื่อมต่อ MongoDB & Backend

          
โครงสร้างไฟล์และคำสั่งเปิดใช้งานเซิร์ฟเวอร์ฐานข้อมูล

        

      


      

        

          1. สถานะการเชื่อมต่อ MongoDB Atlas:
          
ตั้งค่า Connection String ในไฟล์ .env เรียบร้อยแล้ว พร้อมระบบ Auto-Reconnect

          
    
            
  • server.js : Backend API + บันทึกข้อมูลลง MongoDB Atlas
    • 
            
  • models/SensorLog.js : Schema เก็บข้อมูล (ตรวจจับคน Proximity: YES/NO)
    • 
            
  • POST /api/sensors/data : Endpoint สำหรับฮาร์ดแวร์ ESP32 หรือแดชบอร์ด
    • 
            
  • GET /api/sensors/history : ดึงประวัติข้อมูลย้อนหลังจาก MongoDB Atlas
    • 
          

        


        

          2. คำสั่งรันเซิร์ฟเวอร์ & ทดสอบการเชื่อมต่อ:
          

            
# 1. ทดสอบการเชื่อมต่อ MongoDB Atlas โดยตรง:

            
node test_mongo.js

            
# 2. เปิดใช้งาน Backend Server (Port 5000):

            
node server.js

          

          
ตั้งค่า URL ของ Backend ใน config.js แล้วเปิดแดชบอร์ดผ่าน Vercel เพื่อเชื่อมต่อข้อมูลสด
